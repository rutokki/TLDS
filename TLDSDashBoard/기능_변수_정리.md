# 기능 · 변수 정리

`TLDSDashBoard` WPF 프로젝트의 파일별 기능과, 값을 바꿔야 할 때 찾아가야 할 주요 상수/변수를 정리한 문서입니다. 사용 방법이나 실행 절차는 `README.md`를 참고하세요 — 이 문서는 코드를 열어 뭔가 고칠 때 참고하는 레퍼런스입니다.

## 1. 한눈에 보는 데이터 흐름

```
SqliteChannelDataRepository.LoadRecent()   ← DB(SQLite)에서 최근 N개 샘플 읽기 (실패 시 DataGenerator로 대체)
        ↓
MainViewModel._channelData (ChannelDataSet)  ← 60초마다 다시 로드
        ↓
MainViewModel.BuildStaticData()
        ├─ _allChannels (12개 MetricDef)
        ├─ TxChart / RxChart (CombinedChartVM: 채널 6개씩 "레인" 리스트)
        ├─ Kpis (상단 KPI 4개)
        └─ NavItems, DataSourceLabel
        ↓
MainWindow.xaml → SidebarView / TopbarView / KpiRowView / MetricGroupView(×2) / AlarmLogView
                   + DrillModalView(드릴인) / ToastView(익스포트 알림)
```

레인(채널) 위에 마우스를 올리면 `MetricGroupView.xaml.cs`의 `ChartArea_MouseMove`가 시간 인덱스를 계산해서, 그 그룹의 모든 채널(`ChannelSeriesVM.Value`)을 동시에 그 시점 값으로 바꿉니다. 레인의 값 라벨을 클릭하면 `OpenDrillCommand`가 실행되어 `MainViewModel.RecomputeDrill()`이 `DrillData`를 채우고 `DrillModalView`가 뜹니다.

## 2. 폴더/파일별 기능

### Models — 데이터 구조

| 파일 | 기능 |
|---|---|
| `ChannelDataSet.cs` | DB에서 읽어온(또는 대체 생성된) 12개 채널의 `double[]` 배열 + 공통 `Timestamps` (`DateTime[]`, 1분 간격). 필드: `TAC, TV, TFP, TSP, THZ, TA, RFP, RSP, RHZ, RA, RV1, RV2`. |
| `MetricDef.cs` | 채널 1개의 표시 메타데이터: `Id, Name, Unit, ColorHex, Data`. `Decimals`는 `Unit == "Hz"`면 2자리, 아니면 1자리(계산 프로퍼티). |
| `AlarmEventModel.cs` | 알람 로그 한 행: `Time, Channel, Message, Severity`(`AlarmSeverity`: Info/Warning/Critical) + `SeverityLabel`. |

### Services — 데이터 로딩 · 계산 로직

| 파일 | 기능 | 주요 변수 |
|---|---|---|
| `IChannelDataRepository.cs` | DB 읽기 인터페이스. `LoadRecent(int maxSamples)` 한 개 메서드. | — |
| `SqliteChannelDataRepository.cs` | 실제 SQLite 조회 구현. **DB 스키마가 확정되면 여기만 고치면 됩니다.** | `DbPath`("data\\telemetry.db"), `TableName`("Readings"), `TimestampColumn`("Timestamp"), `ColumnMap`(채널Id→실제 컬럼명 12쌍) — 전부 클래스 상단의 `private const`/`static readonly` |
| `DataGenerator.cs` | DB 연결 실패 시 쓰는 대체(샘플) 데이터 생성기 + 알람 로그 목데이터. 채널별 sin파 + 노이즈로 그럴듯한 파형만 생성(실측값 아님). | `SampleCount = 140`(생성 샘플 개수), `GenSeries(base, amp, freq, noise, phase)` 채널별 12번 호출 — 값들은 전부 자리표시자 |
| `Mulberry32.cs` | 시드 고정 PRNG(seed=1337). `DataGenerator`가 매번 같은 모양의 샘플 데이터를 만들도록 함. | — |
| `PathBuilder.cs` | `double[]` 샘플 배열 → WPF `Path` Data 문자열("M x,y L x,y ...") 변환. `PathFromArray(arr,min,max,w,h,padTop,padBottom)`(범위 직접 지정), `PathFromArrayAutoRange(arr,w,h,padTop,padBottom,pad=0)`(배열 자체 min/max 사용). | — |
| `ChartMetrics.cs` | 차트들이 쓰는 고정 좌표 공간(=XAML의 `Canvas Width/Height`와 반드시 일치해야 함). | `KpiSparkW/H/Pad`(200/40/4), `DrillChartW/H/Pad`(900/240/16), `LaneChartW/H/Pad`(900/90/10) |

### ViewModels — 화면 상태

| 파일 | 기능 | 주요 변수/속성 |
|---|---|---|
| `MainViewModel.cs` | 전체 화면의 유일한 ViewModel. DB 로딩, 60초 갱신 타이머, 1초 시계 타이머, KPI/차트/알람/드릴인/토스트 계산을 전부 담당. | 12색 팔레트 상수(`ColorTAC` ~ `ColorRV2`), 상태 색상(`ColorSuccess/ColorCritical/ColorTextSecondary/ColorNavDotInactive`), `windowSize`(표시 구간, 현재 60=최근 60분), KPI로 고른 채널(TV/RV1/THZ + Active Alarms), `_refreshTimer` 간격(60초), `_clockTimer` 간격(1초) |
| `RelayCommand.cs` | `ICommand` 구현체. 파라미터 없는 `Action`과 `Action<object?>` 두 생성자. | — |
| `ViewModelBase.cs` | `INotifyPropertyChanged` 기본 구현 + `SetProperty<T>` 헬퍼. | — |

### ViewModels/Items — 바인딩용 소형 뷰모델

| 파일 | 기능 | 주요 속성 |
|---|---|---|
| `ChannelSeriesVM.cs` | 레인 1개(=채널 1개)의 표시 데이터. | `Id/Name/Unit/ColorHex/Path`, `AxisMaxLabel/AxisMinLabel`(그 구간 실제 최댓값/최솟값), `WindowValues`(호버 조회용 원본 배열), `ValueFormat`, `LatestValue`(호버 해제 시 복귀값), `Value`(현재 표시값 — 호버 중엔 그 시점 값으로 바뀌는 **변경 가능한** 속성) |
| `CombinedChartVM.cs` | TX 또는 RX 그룹 하나. | `Header, Series`(채널 6개), `WindowTimestamps`, `TimeStartLabel/TimeMidLabel/TimeEndLabel`(하단 시간축), `HoverTimeLabel`(호버 중인 정확한 시각 — 변경 가능) |
| `KpiItemVM.cs` | 상단 KPI 카드 1개. | `Label/Value/Unit/ColorHex/SparkPath/DeltaLabel/DeltaColorHex/DeltaBold` |
| `NavItemVM.cs` | 좌측 사이드바 메뉴 1개. | `Id/Label/IsActive/DotColorHex/Badge` |
| `DrillDataVM.cs` | 드릴인 모달에 표시되는 채널 1개의 전체 이력. | `Name/Unit/ColorHex/BigPath/Min/Max/Avg/RangeLabel`(실제 시작~끝 시각) |

### Views — 화면 구성 (UserControl)

| 파일 | 기능 |
|---|---|
| `MainWindow.xaml(.cs)` | 전체 레이아웃 조립(사이드바+본문) + `DataContext = new MainViewModel()` 생성. |
| `SidebarView` | 좌측 메뉴(로고+NavItems). |
| `TopbarView` | 제목/시계(`ClockLabel`)/DB 연동 상태(`DataSourceLabel`)/Export 드롭다운. |
| `KpiRowView` | 상단 KPI 카드 4개. |
| `MetricGroupView` | **핵심 컴포넌트.** TX/RX 각각 한 번씩 재사용(`Data="{Binding TxChart}"` / `Data="{Binding RxChart}"`). 채널마다 위아래로 쌓인 레인(왼쪽=이름/값/클릭, 오른쪽=그 채널만의 실제값 축 차트) + 전체를 가로지르는 호버 십자선/시간칩 + 하단 공용 시간축. |
| `AlarmLogView` | 알람 로그 테이블. |
| `DrillModalView` | 채널 1개 확대 보기(오버레이 모달). |
| `ToastView` | Export 완료 등 알림 토스트. |

### Converters

| 파일 | 기능 |
|---|---|
| `PathDataConverter` | `PathBuilder`가 만든 문자열 → `Geometry` (Path.Data에 바인딩). |
| `HexToBrushConverter` | `"#RRGGBB"` 문자열 → `SolidColorBrush`. |
| `NullToVisibilityConverter` | null(또는 빈 문자열) → Collapsed, 아니면 Visible. 드릴인 모달 표시 여부, 호버 시간칩 표시 여부 등에 사용. |
| `BoldWhenTrueConverter` | bool → FontWeight(SemiBold/Normal). |
| `SeverityToBrushConverter` | `AlarmSeverity` → 배지 배경/글자 브러시(`ConverterParameter="Bg"`/`"Fg"`). `Themes/Colors.xaml`의 `Critical/Warning/Info` 계열 브러시를 참조. |

## 3. 값을 바꿔야 할 때 — 체크리스트

| 바꾸고 싶은 것 | 어디를 고치나 |
|---|---|
| DB 경로 / 테이블명 / 컬럼명 | `Services/SqliteChannelDataRepository.cs` 상단 `DbPath`, `TableName`, `TimestampColumn`, `ColumnMap` |
| 채널 이름(한글 라벨) · 단위 · 색상 | `ViewModels/MainViewModel.cs`의 색상 상수(`ColorTAC` 등) + `BuildStaticData()`의 `_allChannels` 목록 |
| KPI에 표시할 채널 4개 | `MainViewModel.BuildStaticData()`의 `DeltaKpi(...)` 호출부 + `THZ`/`Active Alarms` 카드 부분 |
| 표시 구간 길이(현재 60분) | `MainViewModel.BuildStaticData()`의 `windowSize` 계산부 (`Math.Min(60, ...)`) |
| DB 재조회 주기(현재 60초) | `MainViewModel` 생성자의 `_refreshTimer` `Interval` |
| 레인 차트 크기(현재 900×90) | `Services/ChartMetrics.cs`의 `LaneChartW/H/Pad` — XAML(`MetricGroupView.xaml`)의 `Canvas Width/Height`와 반드시 같이 바꿔야 함 |
| 드릴인 모달 차트 크기 | `ChartMetrics.DrillChartW/H/Pad` (+ `DrillModalView.xaml`의 `Grid Width/Height`) |
| 알람 로그를 DB 연동으로 전환 | 현재 `DataGenerator.GenerateEvents()`(목데이터) — 알람 테이블 스키마를 알려주면 `SqliteChannelDataRepository`와 같은 방식으로 새 리포지토리를 만들어 교체 |
| 폴백(샘플) 데이터의 파형 모양 | `Services/DataGenerator.cs`의 `GenSeries(base, amp, freq, noise, phase)` 호출 인자 12개 |

## 4. 현재 알려진 자리표시자(placeholder)

- `SqliteChannelDataRepository`의 DB 경로/테이블/컬럼명 — 실제 스키마 미확정
- 알람 로그 — 아직 DB 연동 안 됨(목데이터)
- `DataGenerator`의 채널별 base/amplitude/noise 값과 단위(ms 등) — 실제 장비 스펙 미확정
- KPI로 고른 4개 채널(TV/RV1/THZ/Active Alarms) — 임의 선정
